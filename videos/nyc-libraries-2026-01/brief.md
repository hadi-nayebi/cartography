# Library networks across five boroughs

## Question and audience
Where do New York's public-library networks appear across its five boroughs,
and what can a location map tell a curious city resident? Assume no knowledge
of the library systems or planning database. Target 150 seconds; maps carry the
story, with one concise comparison and one concrete building example.

## Scene plan
| Time | Viewer question | Visual and useful point |
| --- | --- | --- |
| 0–18s | Is this one citywide library system? | Large five-borough map; progressively reveal the three source-system colors and name each network. |
| 18–50s | Which network appears where? | Keep points and borough outlines central. Follow NYPL across Bronx/Manhattan/Staten Island; Brooklyn and Queens retain their own colors. No competitive ranking. |
| 50–78s | What do the borough totals count? | Five bars labelled “FacDB public-library records”; same source/filter throughout. Highlight that these are snapshot records, not open-branch counts. |
| 78–112s | Can one place have two records? | Zoom to Bedford; show library and learning-center record cards connecting to one building marker. Explain the adult-learning role through the official branch description. |
| 112–135s | Is a dot proof that I can visit today? | Return to full map; distinguish frozen source date from provider service notices. Point to the three official location finders. |
| 135–150s | What should I remember? | Three networks, a documented snapshot, and a provider check before visiting. Source/reproduction route. |

## Claims and annotations
- System membership comes from the source's `datasource`, corroborated with
  the provider pages in README. System totals from their websites must not be
  mixed with FacDB record totals.
- FacDB 26v1 (June 2026) is the snapshot anchor. Source retrieval October 3
  does not make every input current as of that date.
- Bedford's official history places the branch in its Franklin Avenue building
  since 1905. If used, the anchor belongs on the Bedford scene; it does not
  establish a historical citywide series.
- A library can host adult learning as well as book lending. The Bedford page
  identifies a second-floor learning center; preserve the distinction between
  a program and a separate building.

Keep an eight-second minimum reading window for substantive captions and
separate captions from map labels. Apply the repaired Boston caption-band
clearance before a full render. Determine audio treatment from the developing
review feedback; do not assume a silent storyboard is an approved final film.

## Before rendering
Verify points against the retained borough geometry, inspect the actual map at
phone size, recompute all displayed counts, lock narration/captions and music,
and inspect representative encoded frames. Do not infer walkable access,
capacity, current open status or historical openings from this snapshot.
